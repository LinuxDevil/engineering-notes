<Note>
**Heaps**

To get the parent index you take the current index and divide it by 2 then floor it down

So, if we got a tree like this:

```bash
		100
	99   80
20 18 70 29
```

It will be represented in 

```bash
Index 0 1   2  3  4  5  6  7
Value - 100 99 80 20 18 70 29 
```

So if we need to know the parent of 29, we will take the index (7) and divide it by 2 (7/2=3.5) then floor it to be index (3) which is (80)

If we need to know the children of a node we will multiply it by 2 and add 1 if it is on the right, so 

if you want to know the children of 100, we take 1 * 2 = 2, then 1 * 2 + 1 = 3.
