## How to use the course
1. Read each chapter's articles and redo the examples without looking.
2. Solve the practice problems in order; for each, write the one-line "signal → pattern → trick" in the matching pattern note.
3. Use the framework in [Problem Solving](/Software%20Engineering/DSA/01%20Foundations/Problem%20Solving) on every problem, even easy ones, to build the habit.
4. After the course, move to a curated list (Blind 75, Grind 75 or NeetCode 150, see [DSA Index](/Software%20Engineering/DSA/DSA%20Index)).
